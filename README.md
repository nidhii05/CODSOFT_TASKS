# CODSOFT Java Development Internship

## About

This repository contains the projects completed as part of my
Java Development Internship at CodSoft.

The internship focuses on developing practical Java programming
skills through project-based tasks.

## Tasks Completed

### Task 1 - Number Game

A Java-based number guessing game.

Features:
- Generates a random number between 1 and 100
- Takes the user's guess
- Displays whether the guess is too high or too low
- Counts the number of attempts
- Supports multiple rounds
- Calculates the score

### Task 2 - Student Grade Calculator

A Java program that calculates student results.

Features:
- Takes marks for multiple subjects
- Calculates total marks
- Calculates average percentage
- Assigns a grade
- Displays the final result

### Task 3 - ATM Interface

A Java-based ATM simulation.

Features:
- Check account balance
- Deposit money
- Withdraw money
- Validates withdrawal amount
- Displays transaction messages
